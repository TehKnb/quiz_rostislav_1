## З чого почати

1. Відкрийте `START-HERE.html` у браузері: це повна інструкція передачі.
2. Прочитайте `docs/HANDOFF.md`: архітектура, запуск, персоналізація, API, база, перенесення, інтеграції та приймання.
3. Вихідний код знаходиться в корені репозиторію (`app/`, `package.json` та конфігурації). Після експорту із зазначеного commit у нього внесено заміну D1 на webhook, відеокейси, новий логотип і перехід із Cloudflare Workers на Node.js для Railway; актуальний опис — у `docs/HANDOFF.md`.
4. У `docs/QUESTIONS.md` наведені запитання всіх відмінних гілок. `questions-all-branches.json` містить 55 поєднань сфери й формату команди.
5. У `examples/` — синтетичні приклади заявки, відповіді сервера, payload webhook та 4 контрольні результати для перевірки перенесення.
6. `MANIFEST.sha256` містить контрольні суми початкового пакета, до змін, зі шляхами `source/…` того часу; з поточними файлами він не збігається.

Це вихідний проєкт із документацією, а не лише технічне завдання. Архів не містить реальних заявок, бази з персональними даними, ключів, Git-авторизації, node_modules чи облікових записів. Квіз B до цього пакета не входить. Робочий сайт не змінювався.

## Межі готовності

Інтерфейс, питання, результати та передача заявок на webhook (`BUSINESS_REVIEW_WEBHOOK_URL`) реалізовані; база даних не використовується. Запитання для власної сфери формулює OpenAI (`OPENAI_API_KEY`). Сповіщення менеджерам, рекламні пікселі, облік UTM, потребують окремого підключення. Деплой описано в `docs/HANDOFF.md`, розділ 10.

Контрольні тести й TypeScript перевірено 02.11.2026 в наявному середовищі з встановленими залежностями. Чисте встановлення на комп'ютері команди та розгортання поза Sites у межах передачі не виконувались.

## Застосунок

Квіз на Next.js (App Router) для Node.js. База даних не використовується: заявки передаються на webhook, а запитання для власної сфери формулює OpenAI.

## Локальний запуск

Потрібні Node.js 22 і pnpm 11.25.0 (`corepack pnpm@11.25.0 ...`, якщо pnpm не встановлено).

```bash
pnpm install --frozen-lockfile
cp .env.example .env.local
pnpm dev
```

## Production

```bash
pnpm build
pnpm start
```

Сервер слухає `0.0.0.0:$PORT` (типово 3000). `GET /health` повертає 200, коли сервер готовий.

## Змінні оточення

| Змінна | Призначення |
|---|---|
| `BUSINESS_REVIEW_WEBHOOK_URL` | Адреса вебхука заявок. Без неї форма показує помилку відправки |
| `OPENAI_API_KEY` | Ключ OpenAI. Без нього власна сфера отримує універсальні запитання |
| `OPENAI_MODEL` | Необов'язкова модель, типово `gpt-4o-mini` |
| `OPENAI_BASE_URL` | Необов'язкова адреса шлюзу або тестового сервера |

Усі змінні доступні лише серверу. У production їх задають у Railway Variables.

## Перевірки

```bash
node tests/engine.cjs
node tests/lead-payload.mjs
pnpm exec tsc --noEmit
pnpm lint
pnpm build
```

`tests/lead-payload.mjs` читає дані з `docs/` і `examples/`. Деплой описано в `docs/HANDOFF.md`, розділ 10.
